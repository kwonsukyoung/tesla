# 🚗 블랙박스 범인 잡기 (Dashcam Culprit Finder)

주차 중 차량 긁힘(문콕, 물피도주, 왼쪽 뒷 필러 접촉 등) 용의 차량 및 보행자를 찾기 위해 **수많은 블랙박스 영상을 일괄 분석하여 움직임 및 접촉 의심 장면만 자동으로 추출해 주는 웹 애플리케이션**입니다.

---

## ✨ 주요 기능

1. **대량 블랙박스 영상 일괄 분석 (Batch Processing)**
   - 수십~수백 개의 `MP4`, `AVI`, `MOV`, `MKV` 블랙박스 파일을 한 번에 드래그 앤 드롭하거나 폴더 경로로 불러와 고속 스캔합니다.
2. **차량 주변 움직임 & 근접 접촉 자동 감지 (OpenCV + Canvas 하이브리드)**
   - 배경 차분(MOG2) 및 픽셀 변화량 분석을 통해 단순 원거리 통행은 걸러내고, 차량 가까이 접근하거나 머무르는 움직임을 집중 포착합니다.
   - **미세 흔들림(충격 의심) 감지**: 차량이 긁히거나 부딪힐 때 발생하는 전체 화면의 순간적인 미세 흔들림을 함께 표시합니다.
3. **관심 영역(ROI) 집중 감시 (왼쪽 뒷 필러 등 특정 부위 지정)**
   - `전체 영역`, `좌측 집중(왼쪽 필러/측면)`, `우측 집중`, `하단 근접` 프리셋 제공
   - 영상 화면 위에서 마우스 드래그로 **내가 원하는 위치(예: 왼쪽 뒷 필러 주변)**만 직접 지정하여 오탐을 대폭 줄일 수 있습니다.
4. **용의 장면 스냅샷 & 번호판 판독용 확대 플레이어**
   - 감지된 장면마다 **최대 움직임 순간의 스냅샷(감지 박스 표시)**과 시간대, 위험도 점수를 카드로 정리합니다.
   - 카드 클릭 시 해당 영상의 **감지 2초 전 지점**부터 즉시 재생하며, **마우스 휠/버튼 줌(최대 5배 확대)** 및 **0.25x 슬로모션**, **고화질 증거 화면 캡처(PNG)** 기능을 제공합니다.
5. **설치 없이도 동작하는 듀얼 엔진 구조**
   - **Python 백엔드 모드 (`app.py`)**: OpenCV(`cv2`) 멀티스레딩 고속 분석 및 로컬 폴더 직접 스캔 지원
   - **브라우저 단독 모드 (`static/index.html`)**: 파이썬 실행 없이 HTML 파일만 열거나 GitHub Pages에 배포해도 브라우저 내장 고속 프레임 분석기로 즉시 작동

## 🚀 실행 방법

### 방법 1: Python 백엔드 + 웹 UI 실행 (권장 - 대용량 고속 분석)

```bash
# 1. 폴더 이동
cd "범인잡기"

# 2. 가상환경 생성 및 패키지 설치
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

# 3. 서버 실행 (실행 시 브라우저가 자동으로 열립니다)
python3 app.py
```
- macOS에서는 폴더 안의 **`run.command`** 파일을 더블클릭하면 패키지 확인 후 서버가 자동 실행됩니다.
- 서버 실행 후 브라우저에서 `http://127.0.0.1:8000` 으로 접속합니다.

### 방법 2: 설치 없이 바로 실행 (브라우저 고속 분석 엔진)
- `static/index.html` 파일을 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 웹 브라우저로 바로 열어도 모든 핵심 기능(일괄 영상 투입, 좌측/특정 영역 ROI 마우스 지정, 움직임 자동 추출, 번호판 확대/슬로모션 판독)을 그대로 사용할 수 있습니다.


## 💡 왼쪽 뒷 필러 긁힘 범인 빠르게 찾는 팁

1. **전방/후방 영상 중 후방(또는 좌측이 보이는 채널) 영상들을 먼저 일괄 선택**하세요.
2. 상단 **[감지 영역(ROI) 설정]**에서 **`좌측 집중 (왼쪽 뒷 필러/측면)`** 프리셋을 누르거나, 영상 미리보기 위에서 **왼쪽 뒷 필러 쪽 통로만 마우스로 드래그**해 주세요.
3. **[분석 시작]**을 누르면 움직임이 있었던 구간만 썸네일 카드로 추출됩니다.
4. 추출된 카드 중 **`충격/접촉 의심`** 또는 **`높은 움직임`** 배지가 붙은 장면을 클릭해 **`0.25x` 배속 + 화면 확대(Zoom)**로 번호판과 차종을 확인하고 **[증거 캡처 저장]**을 누르세요.
